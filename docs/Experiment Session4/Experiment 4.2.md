Experiment:SLAM Lidar data Interaction

Hardware: Lidar Sensor, ROS2 Development Environment

Communication: USB/Serial.Connected with ROS2.

What I learned: I learned how to use the SLAM algorithm in ROS2 to process Lidar data and create a map of the environment. and how to visualize the Lidar data in RViz2.
